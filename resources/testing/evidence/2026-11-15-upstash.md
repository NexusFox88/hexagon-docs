# Upstash Box acceptance

## Registered Connector and primitive checks

`integrations/sandboxes/upstash.ts` provisions Node EphemeralBox resources with provider TTL and operation-derived names. It reconciles exact names, preserves nonzero command exits, imposes remote GNU timeout deadlines, detaches bounded background commands, transfers binary files and supplies a request-scoped private HTTP tunnel. No provider built-in agent is used. Configuration is `size: small | medium | large`; network allowlists and pause/resume are not advertised.

`NODE_USE_ENV_PROXY=1 npx tsx tooling/smoke-upstash.ts` passed at 09:18:13–09:18:36 UTC. Private journal `.local/evidence/upstash-connector-ac2dd282-b819-42a1-9be1-b324cec9fbbd.json` records a real resource, 256 KiB binary file roundtrip, missing-command exit 127, one-second timeout exit 124, Runtime protocol 1 readiness, anonymous 401, reconstruction of a new Connector with exact operation lookup, and absence-confirmed deletion. The returned provider deadline was recorded; natural TTL expiry was not exercised in this probe.

The transport adapts authenticated exec-session callbacks to the shared stdio/TCP tunnel. It bounds queued output to 8 MiB and total input to 16 MiB per tunnel connection because the SDK exposes no callback-level backpressure controls. Overflow and abnormal exit fail the transport. Remote EOF ends the HTTP body; close releases the exec session. Three focused tests cover exact byte/EOF delivery, bounded output for a slow reader and abnormal-session failure.
