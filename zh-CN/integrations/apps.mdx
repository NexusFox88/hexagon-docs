应用连接器把固定的第三方操作接入 ToolBroker。一个 Connection 表示一个租户所属账户和所选操作，不是应用的全部 API。应用凭据留在控制平面，Session 只绑定使用权限。

## 创建连接并选择操作

下面以 Notion 只读配置为例。先把专用测试页面分享给 integration，并开放所需评论读取权限。这里创建连接不执行搜索或读取；验证会请求账户身份。环境变量来自私有配置，hosted 初始化见[自托管](/zh-CN/operate/self-host)。保存返回 ID 后复用。

```python
import os
from hexagon import Hexagon
client = Hexagon.local()
connection = client.create_connection(
    kind="tool", provider="notion", name="Project notes",
    credential=os.environ["NOTION_TOKEN"],
    config={"authentication":"api_key", "operations":["search","read_blocks","read_comments"]},
)
checked = client.validate_connection(connection["id"])
if checked["status"] != "ready":
    raise RuntimeError("Inspect account and permission diagnostics")
client.update_connection(connection["id"], enabled=True)
```

```typescript
import { Hexagon } from '@hexagon/agent-sdk';
const client = await Hexagon.local();
const credential = process.env.NOTION_TOKEN;
if (!credential) throw new Error('Set NOTION_TOKEN');
const connection = await client.createConnection({
  kind: 'tool', provider: 'notion', name: 'Project notes', credential,
  config: { authentication: 'api_key', operations: ['search','read_blocks','read_comments'] },
});
const checked = await client.validateConnection(connection.id);
if (checked.status !== 'ready') throw new Error('Inspect account and permission diagnostics');
await client.updateConnection(connection.id, { enabled: true });
```

按 [Tools 绑定](/zh-CN/build/tools)把 connection.id 放到 `tools: {notes: connection_id}`，使用支持 Tools 的 Harness。提交明确任务读取测试页面及评论，检查实际 Tool 结果、分页和子块，不能只核对 Agent 的自然语言结论。两套 SDK 独立执行并关闭 Session。

操作默认选择非写项；显式 operations 只能选本页列出的 ID。所有写操作必须审批，replay=never；读操作也可能计费。授权、操作选择、第三方 scope 和具体资源分享是不同条件，任何一个缺失都可能拒绝调用。

## OAuth 与权限证据

有 OAuth 的应用先注册部署/租户自己的 OAuth client，设置精确 callback URL，再从 Console 授权账户。没有内置共享授权 SaaS。Google 服务是独立连接与 consent，Microsoft 使用 delegated 权限。凭据通道的 HTTPS 入口不是 OAuth 管理 callback 的替代。

查看 allowed_operations、scope_source、permission_checks 和 permission_coverage：本地允许的操作不等于 Provider 实际授予 scope。partial/unknown 不能写成全部权限验证。验证不执行写入；资源分享和字段权限仍可能影响实际调用。

Token refresh 与重新授权不同；不确定的 refresh 结果需要重新授权，不能盲重用可能已旋转的 refresh token。变更账户/权限使旧策略失效，使用新 Session。disconnect 只停止 Hexagon 本地使用，不撤销 Provider 端 Token，也不能收回已经发送的请求。详见[授权](/zh-CN/build/tool-authorization)。

### Notion (`notion`)

**配置 / 鉴权**：Integration/PAT Token；支持 OAuth。

**权限与限制**：共享目标页面给 integration；页面属性不等于正文，read_blocks 只读直接子块，递归与分页需逐次读取；评论还需 comment-read 权限。

| 操作 | 必填参数 | 审批 | 实现描述 |
| --- | --- | --- | --- |
| `search` | — | 默认不要求 | Search accessible Notion pages by title. Results are limited to granted content. |
| `read_page` | `page_id` | 默认不要求 | Read page properties. Use read_blocks for page content. |
| `read_blocks` | `block_id` | 默认不要求 | Read direct child blocks; follow child IDs and pagination for complete content. |
| `read_comments` | `block_id` | 默认不要求 | Read accessible comments attached to a page or block; requires comment-read capability. |
| `create_page` | `parent_page_id`, `title` | 必须 | Create a child page with a title and plain text paragraph. |
| `append_text` | `page_id`, `text` | 必须 | Append a paragraph to an existing page. |
| `update_paragraph` | `block_id`, `text` | 必须 | Replace the text of a paragraph block. |
| `add_comment` | `page_id`, `text` | 必须 | Add a comment to a page. |

**具体读取示例**：选择 `search`，参数为 `{"query": "Hexagon acceptance", "page_size": 10}`。按标题找到已共享的测试页，再用 read_blocks/read_comments 读取内容；搜索不是完整阅读。

**最小 Token 配置**：`{"authentication": "api_key", "operations": ["search"]}`。凭据格式见上文；使用托管 OAuth 时应走部署的同意流程，不直接把 OAuth token 填入此示例。

## 错误、变更与对账

401 使凭据失效，403 可能是资源/操作权限，429 是速率或额度问题。写请求已派发后出现不确定响应，必须查看原调用及 request_hash，在第三方记录中核对后[对账](/zh-CN/operate/reconciliation)，不能重放来确认。Linear mutation 的 GraphQL errors 即使伴随 data=null 也不能证明零副作用。

新 Session 固定账户标识的能力取决于 Provider 是否提供稳定身份；旧快照不能追溯获得该保证。目录中的 provider 存在只证明有适配，不证明账户有权限或服务当前健康。本页没有执行新的第三方操作或 OAuth consent，也未发送邮件/消息。
