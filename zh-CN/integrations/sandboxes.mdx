Sandbox 提供云执行环境；Harness 在其中执行 Agent 任务。local / hosted 描述控制平面位置，两者都可以使用这些云 Provider。先按所需能力筛选，再核验具体 Harness、模型协议与 SDK 的组合证据。

## 当前注册能力

所有下列目标均声明文件、命令和私有预览能力。“不支持”表示当前 Hexagon 连接器未提供该能力，不评价供应商其他产品。表格依据当前注册表和连接器，不是实云验收结果。

| Provider | API provider | 域名 allowlist | OCI | 空闲策略 |
| --- | --- | --- | --- | --- |
| [E2B](/zh-CN/integrations/sandboxes/e2b) | `e2b` | 支持 | 公开镜像构建 | pause / connect |
| [Modal](/zh-CN/integrations/sandboxes/modal) | `modal` | 支持 | 公开及私有 | snapshot / recreate |
| [Blaxel](/zh-CN/integrations/sandboxes/blaxel) | `blaxel` | 不支持 | 不支持 | automatic standby |

## 如何理解条件

- **网络**：只有 E2B 和 Modal 声明 network_allowlist。请求不支持的限制会在分配前失败，不能默默退化为开放网络。还需考虑控制平面凭据入口、模型和 Tools 的实际调用路径。
- **OCI**：Modal 直接使用 OCI 并可处理私有镜像；Fly Machines 为公开镜像；E2B 通过 Session 自有 Template 准备公开镜像。镜像可解析、可构建和 Harness 可执行是三个检查，具体看 [OCI 指南](/zh-CN/integrations/harnesses/oci)。
- **暂停**：E2B、Freestyle、Instabox 使用保留内存的策略；文件系统策略不保证任意进程或内存继续。Fly Machines 允许冷启动回退。Modal 快照重建会改变底层资源 ID，Session ID 保持稳定。
- **自动 standby**：Blaxel / Sprites 由 Provider 控制时机，不是 Hexagon 确认的显式暂停。无法观察的实际计算或计费状态属于未知，不能从空闲计时器推断。
- **删除**：暂停、stop、快照均不等于清理。关闭 Session 后需确认资源及关联端点、镜像准备资源的清理结果。

Fly Sprites 与 Fly Machines 使用不同 API 和生命周期，不能交换配置。Daytona 不在当前公开注册表；历史原型不是新建连接的支持承诺。

## 配置与首次验证

1. 从 Console 的 Sandbox 配置入口选择 provider，或通过管理客户端 create_connection / createConnection 创建 kind=sandbox 的连接。读取该 Provider 的配置 schema 和 setup_url；不要将另一个 Provider 的字段套用进来。
2. 将 Provider 凭据作为连接 credential 提交，保留在控制平面。不要加入 Agent env、项目文件或前端代码。
3. 验证连接，再明确启用。验证操作的范围取决于 Provider；成功列举资源不代表具有所有创建、镜像构建或删除权限。
4. 用兼容 Harness 和模型预检 Session，再完成实际任务、文件读写、所需预览和最终清理。先从 [E2B 接入](/zh-CN/integrations/sandboxes/e2b)或[首个 Session](/zh-CN/start/first-session)开始。
5. 需要休眠时独立验证第二轮自动唤醒与文件、对话连续性，不以单轮成功代替。

模板、镜像、地区、CPU、内存等字段依 Provider schema 而定。Session 的 timeout / idle 设置不等于统一云机器规格。修改连接会使验证失效并禁用；已有 Session 保留固定配置，见[连接变更](/zh-CN/build/connection-lifecycle)。

## 能力标签与验证状态分开阅读

| 标签 | 本页中的含义 |
| --- | --- |
| 支持 | 当前连接器声明对应接口，例如十一项均声明 files、commands、preview；实际权限和目标场景仍需另行验证。 |
| 有条件 | 接口有明确分发或生命周期前提，例如 E2B 公有 OCI 准备，或只保留文件系统而不承诺进程内存。 |
| 不支持 | 当前连接器缺少该接口，上表以“否”表示；不能由此推断供应商其他产品也无此能力。 |
| 未知 | 证据不足以确定目标真实行为、账户条件或计费状态；其他能力通过不能将其改成“支持”。 |

允许列表的“是”表示连接器支持，不是所有域名或绕过情形的统一保证。OCI 单元格带镜像分发条件；空闲列只命名策略，不表示清理状态，也不证明内存保留。执行和恢复结果见[已验证组合](/zh-CN/integrations/verified-combinations)，配置与生命周期细节见[Sandbox Provider 契约](https://github.com/NexusFox88/hexagon-docs/blob/main/resources/docs/sandbox-providers.md)。

编辑依据：十一行及能力标记已与导出的 `sandboxConnections` 注册表比较，策略描述另行依据生命周期契约。注册表 `evidence` 标签仍是声明，不独立证明每个单元格的真实旅程。注册表或连接器变化后，需要重新核对本表及对应 Provider 页。
